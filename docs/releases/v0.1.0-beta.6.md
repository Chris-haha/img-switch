# IMG Switch v0.1.0-beta.6

这一版修复配置误覆盖与出图可靠性，并补齐失败任务的查询、取消和恢复。

- 保存前检查配置损坏与修改冲突，保留上一份有效配置；编辑、排序、删除中转源不再串位覆盖。
- Codex 开关对齐原生技能启停规则；Cursor 共享技能冲突会明确提示，避免显示无法落实的关闭状态。
- 新增测试出图、任务历史、详情、状态筛选、分页和仅重试未完成项；界面显示实际尺寸与耗时。
- HTTP 408/5xx、发送后超时或断连、生成后下载失败保留「结果未知」，不会自动重复发起可能计费的请求。
- 严格检查 PNG/JPEG；支持常见渐进式 JPEG，拒绝截断或不完整图像；本地解码不可用会明确停止。
- 补齐非标准密钥及 URL/JSON 编码脱敏，保护同名并发输出，修复取消冲突与子进程清理。

安装包内含运行环境，无需预装 Python。启动新版时会更新已由 IMG Switch 管理的技能副本，配置保留。

测试版安装包尚未正式签名；macOS 未公证。下载后请核对平台及 SHA-256。

费用以中转服务商实际记录为准。「结果未知」不代表已扣费或未扣费，重试前应核对请求 ID。宿主发现技能可用也不保证模型每次选择该技能。多参考图、透明背景等未列出的参数能力不在本版范围内。
